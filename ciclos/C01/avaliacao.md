# Avaliação do ciclo

Preenchida pelo NIAR-Saúde. Um bloco por requisito.
Verifica o Fairness Report com as evidências e aponta para os campos do relatório, sem reescrever os fatos. O resultado do requisito e a situação dos itens ficam só aqui. O texto dos requisitos e a explicação de cada item estão no guia de avaliação. As perguntas do checklist estão reproduzidas em cada bloco para registrar o que foi verificado neste ciclo.

| Campo                                                            | Preenchimento |
| ---------------------------------------------------------------- | ------------- |
| ID do ciclo                                                      |               |
| Avaliador(es) NIAR                                               |               |
| Referências do FIAR usadas (tag)                                |               |
| Dimensões avaliadas                                             | Justiça      |
| Fairness Report verificado (versão e data)                      |               |
| Pré-preenchimento do relatório (agente da sala segura ou NIAR) |               |

Resultados possíveis: Atendido | Não atendido | Inconclusivo (registrar o motivo) | Não aplicável.
Atendimento parcial ou prática apenas planejada não levam automaticamente a Inconclusivo: com evidência suficiente de não atendimento, o resultado é Não atendido.
Sem Fairness Report entregue no prazo, o resultado é Inconclusivo, com o motivo "relatório de dimensão não entregue", salvo evidência suficiente de não atendimento.
Os estados do Fairness Report (Analisável Sim/Não; justificada, injustificada ou sem conclusão; considerada, realizada ou descartada; OBRIGATÓRIO/CONDICIONAL) são da equipe. Não são resultado nem situação de item.

Lacuna (RCxx-Ly): ponto do Fairness Report que impede concluir ou atender o requisito. Antes de abrir, verificar: (1) é necessária para que o requisito possa ser atendido? (2) a resposta já está no relatório? (3) já foi apontada? Só abrir se (1) for sim e as demais forem não. Posição da equipe só em comunicação, em outro artefato ou marcada [a confirmar] não conta como resposta. Pergunta à equipe sobre o conteúdo do requisito é lacuna, não pendência.
Pendência (RCxx-Px): só para aplicabilidade, verificação interna do NIAR, decisão metodológica ainda não tomada ou pedido que não cabe no relatório. (1) é necessária? (2) já está em alguma fonte? (3) já foi respondida? Pendência de aplicabilidade não é lacuna.
Lacuna ou pendência aberta só torna o requisito Inconclusivo quando impede a conclusão. Divergência da Seção 0 que não afeta nenhum requisito da dimensão: recomendação do NIAR.
