# Consolidação da Avaliação

Esta pasta reúne os registros utilizados para consolidar a avaliação técnica da combinação:

**Tarefa de IA + Versão Avaliável + Contexto de Uso.**

A consolidação considera os achados das sete dimensões e não resulta de soma, média ou percentual de requisitos atendidos.

## Resultado de conformidade

Os estados possíveis são:

- **Conforme:** há evidência suficiente para concluir e não foram identificadas inadequações materiais incompatíveis com o Contexto de Uso;
- **Pendente:** ainda faltam evidências, esclarecimentos, análises ou decisões necessárias para concluir sobre questão relevante;
- **Não Conforme:** há evidência suficiente para demonstrar inadequação material relevante.

A ausência de documentação, isoladamente, não determina Não Conformidade.

## Estrutura

### `template_consolidacao_avaliacao.md`

Template utilizado para consolidar a avaliação técnica.

### `evidencias_consolidadas/`

Pode reunir referências ou sínteses das evidências utilizadas na consolidação, sem duplicar desnecessariamente os artefatos originais.

### `parecer_final/`

Destina-se aos documentos finais derivados da consolidação, quando aplicáveis.

A decisão institucional, quando necessária, é registrada separadamente em `decisao_institucional/`.
