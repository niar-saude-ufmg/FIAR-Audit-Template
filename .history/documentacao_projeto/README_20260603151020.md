# Documentação do Projeto

Este diretório reúne a documentação institucional do projeto auditado.

## O que incluir aqui

| Documento                                | Obrigatório  | Descrição                                             |
| ---------------------------------------- | ------------- | ------------------------------------------------------- |
| Escopo do projeto                        | Sim           | Finalidade, uso pretendido e uso proibido do sistema    |
| Aprovação institucional (CIIA)         | Sim           | Parecer formal com condicionantes documentadas          |
| Identificação do responsável técnico | Sim           | Nome nominal do responsável pelo projeto               |
| Classificação de risco do sistema      | Sim           | Registro da classificação de risco atribuída         |
| Aprovação ética (CEP-UFMG)            | Se aplicável | Obrigatório para projetos que utilizam dados de saúde |

> Esses documentos correspondem ao Bloco 1.1 — Governança Institucional do checklist operacional do FIAR-Saúde e são verificados na primeira camada da auditoria. A ausência de qualquer item obrigatório implica classificação imediata como Não Conforme.
