# Revisões Periódicas

Esta pasta reúne revisões realizadas em intervalos definidos ou após gatilhos relevantes.

A revisão periódica avalia se a tarefa continua:

- dentro do escopo;
- adequadamente documentada;
- associada à versão avaliada;
- monitorada;
- acompanhada por responsáveis;
- sujeita aos controles previstos;
- compatível com o Contexto de Uso.

A revisão periódica não substitui uma nova avaliação quando houver mudança relevante.
---
## 1. Frequência

A frequência deve ser definida conforme:

- risco;
- impacto;
- volume;
- velocidade de mudança;
- incidentes;
- condicionantes;
- requisitos institucionais;
- regulação;
- disponibilidade de evidências.

---

## 2. Gatilhos extraordinários

Realizar revisão adicional quando houver:

- incidente;
- mudança de versão;
- drift;
- disparidade;
- reclamação relevante;
- alteração regulatória;
- mudança de população;
- mudança de Contexto de Uso;
- alteração de responsáveis;
- descumprimento de condicionante;
- decisão institucional;
- mudança de infraestrutura.

---

## 3. Arquivos

Utilizar:

```text
periodic_review_template.md
```

Exemplos:

```text
periodic_review_2026-Q1.md
periodic_review_2026-semestral.md
periodic_review_pos-incidente-INC-OP-001.md
```

---

## 4. Resultado

A revisão pode recomendar:

* continuidade;
* continuidade com ações;
* atualização documental;
* análise adicional;
* monitoramento reforçado;
* restrição;
* suspensão técnica;
* nova avaliação;
* escalonamento institucional.

A recomendação técnica não substitui decisão institucional.
