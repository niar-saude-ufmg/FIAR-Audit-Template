# Formulário de Entrada do Projeto no FIAR-Saúde

## Orientações

Este formulário é o primeiro contato estruturado entre o projeto e o NIAR-Saúde.

Seu objetivo é permitir uma compreensão inicial da solução, do estágio atual e do contexto de uso. Não é necessário realizar novas análises técnicas para preenchê-lo.

Preencha apenas informações já conhecidas pela equipe. Quando algo ainda não estiver definido, use:

```text
[INFORMAÇÃO PENDENTE]
```

O formulário não substitui Data Card, Model Card, análise de riscos ou outros artefatos técnicos.

---

Após o recebimento, o NIAR-Saúde:

1. fará a triagem inicial;
2. identificará a tarefa ou as tarefas de IA;
3. solicitará entrevista apenas se houver dúvidas relevantes;
4. preparará a minuta de `documentacao_projeto/identificacao_avaliacao.md`;
5. indicará quais artefatos técnicos serão necessários para o ciclo de avaliação.

O preenchimento deste formulário não constitui resultado de conformidade, certificação técnica, validação clínica ou autorização de implantação.
