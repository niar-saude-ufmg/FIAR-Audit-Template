# Entrada do Projeto

Esta pasta contém o formulário inicial preenchido pela equipe do projeto.

## Fluxo

1. O projeto preenche `formulario_entrada_projeto.md`.
2. O NIAR-Saúde faz a triagem.
3. Uma entrevista é realizada apenas quando houver dúvidas ou ambiguidades.
4. O NIAR-Saúde prepara `documentacao_projeto/identificacao_avaliacao.md`.
5. O projeto valida as informações factuais.
6. O NIAR-Saúde consolida tarefa, versão, contexto, trilha e escopo.

As informações básicas devem ser fornecidas uma única vez e reaproveitadas nos documentos posteriores.

Não inclua dados pessoais, dados clínicos individuais, credenciais, chaves ou materiais sensíveis não autorizados.
