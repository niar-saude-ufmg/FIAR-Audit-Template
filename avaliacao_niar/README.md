# Avaliação do NIAR

Este diretório é preenchido exclusivamente pelo NIAR (Núcleo de Inteligência Artificial Responsável para a Saúde). A equipe do projeto não deve incluir documentos aqui.

## O que será depositado aqui pelo NIAR

| Documento                        | Descrição                                                                                                                            |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Checklist operacional preenchido | Verificação de presença, consistência cruzada e rastreabilidade dos artefatos                                                      |
| Registro de inconsistências     | Inconsistências identificadas classificadas por grau (Leve, Moderada, Grave)                                                          |
| Resultado por dimensão de IAR   | Avaliação das sete dimensões: Governança, Segurança, Privacidade, Responsabilização, Rastreabilidade, Justiça e Transparência |
| Classificação de conformidade  | Conforme, Pendente ou Não Conforme para a combinação (Tarefa, Versão Avaliável)                                                   |

> A separação entre artefatos produzidos pelo projeto e avaliações conduzidas pelo NIAR é um princípio estrutural do FIAR-Saúde. O projeto não avalia a si próprio.
>
