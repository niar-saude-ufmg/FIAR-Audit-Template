# Avaliação do NIAR

Este diretório é utilizado **exclusivamente** pelo NIAR (Núcleo de Inteligência Artificial Responsável para a Saúde) no contexto do ciclo de auditoria FIAR-Saúde.

A equipe do projeto **não** deve criar, modificar ou remover arquivos neste diretório.

---

## Papel no ciclo de auditoria

Este diretório contém os resultados da avaliação independente realizada pelo NIAR sobre a combinação:

> (Tarefa, Versão Avaliável)

Ele representa a etapa de verificação externa da conformidade em relação aos requisitos do FIAR-Saúde.

---

## Conteúdo produzido pelo NIAR

| Documento                             | Descrição                                                           |
| ------------------------------------- | --------------------------------------------------------------------- |
| Checklist operacional preenchido      | Verificação de completude, consistência cruzada e rastreabilidade  |
| Registro de inconsistências          | Inconsistências identificadas, classificadas por severidade          |
| Avaliação por dimensão de IAR      | Julgamento das dimensões: Governança, Segurança, Privacidade, etc. |
| Classificação final de conformidade | Resultado global: Conforme, Pendente ou Não Conforme                 |

---

## Princípio de independência

A separação entre artefatos produzidos pelo projeto e avaliações conduzidas pelo NIAR é um princípio central do FIAR-Saúde.

O projeto não realiza autoavaliação.
