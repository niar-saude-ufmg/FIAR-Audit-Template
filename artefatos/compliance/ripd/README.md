# Relatório de Impacto à Proteção de Dados Pessoais — RIPD

Esta pasta contém o Relatório de Impacto à Proteção de Dados Pessoais ou os registros relacionados à sua elaboração, quando aplicável.

O arquivo:

```text
RIPD.docx
```

deve ser tratado como modelo ou documento institucional e não como artefato metodológico produzido pelo FIAR-Saúde.

O conteúdo, a aprovação e a eventual dispensa do RIPD dependem da análise da área institucional competente em proteção de dados.

---

## 1. Finalidade

O RIPD deve documentar, conforme o modelo institucional aplicável:

* os tratamentos de dados pessoais realizados;
* suas finalidades;
* as categorias de titulares;
* as categorias de dados;
* os agentes de tratamento;
* os fluxos de compartilhamento;
* os riscos aos direitos e liberdades dos titulares;
* as medidas de prevenção, segurança e mitigação;
* os responsáveis;
* as condições de revisão.

Este README não substitui o conteúdo formal do RIPD.
