# Registro Consolidado de Condicionantes Institucionais

Este arquivo consolida as condicionantes estabelecidas em decisões institucionais relacionadas às Tarefas de IA do projeto.

O conteúdo integral de cada decisão deve permanecer no respectivo Registro de Decisão Institucional.

Este arquivo fornece uma visão atual das condicionantes, responsáveis, prazos e evidências de cumprimento.
