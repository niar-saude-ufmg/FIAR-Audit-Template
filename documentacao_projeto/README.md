# Documentação do Projeto

Este diretório contém a documentação inicial da instância de auditoria FIAR-Saúde.

Seu objetivo é registrar o contexto do projeto auditado e apoiar a definição do escopo da auditoria.

---

## Conteúdo

* `identificacao_auditoria.md` → metadados formais da auditoria (projeto, tarefa, versão avaliável, trilha, responsáveis)

---

## Observação

Este diretório não contém documentação completa de governança institucional ou avaliação.

Essas informações são registradas em outros componentes do repositório, conforme a estrutura do FIAR-Audit-Template.
