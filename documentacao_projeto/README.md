# Documentação do Projeto

Este diretório contém a documentação inicial da instância de auditoria FIAR-Saúde.

Ele define o escopo formal da auditoria e serve como ponto de entrada para a avaliação da combinação:

> (Tarefa, Versão Avaliável)

---

## Papel no ciclo de auditoria

A documentação aqui registrada estabelece:

- o sistema de IA a ser auditado;
- o contexto clínico ou operacional da tarefa;
- a versão avaliável que será submetida à auditoria;
- a trilha de execução (Experimental ou Produção);
- os responsáveis técnicos pelo sistema.

Esta etapa marca o início formal do ciclo de auditoria FIAR.

--- 

## Conteúdo

* `identificacao_auditoria.md` → metadados formais da auditoria:
  - definição da tarefa (modelo + dados + objetivo)
  - versão avaliável
  - trilha de execução
  - responsáveis técnicos
  - data de início da auditoria

## Observação

Este diretório não contém artefatos técnicos de desenvolvimento nem resultados da auditoria.

- Artefatos técnicos → `artefatos_projeto/`
- Avaliação independente → `avaliacao_niar/`
- Resultado final → `auditoria_final/`
